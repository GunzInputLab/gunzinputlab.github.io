Page 02 · Start here

Rapid Trigger, in normal words.

A normal actuation point turns a key ON at one fixed depth. Rapid Trigger lets the key turn OFF and ON again from your movement direction instead of waiting for one fixed reset point.

Three settings. Three different jobs.

Official behavior: The first downward point where the released key turns ON.

In GunZ: It controls when the first direction or action begins.

Official behavior: How far you lift after a key is active before it turns OFF.

In GunZ: It controls how much release movement clears the old direction or action.

Official behavior: How far you press down after reversing before the next ON.

In GunZ: It controls how much re-press movement is needed before the next direction, dash, or repeated action.

These values are distances in millimeters—not timing values. A smaller distance can happen sooner under the same finger motion, but the real time still depends on your hand, keyboard scanning, game, and connection.

Page 03 · The full motion

Read one complete key cycle.

This order keeps RT D and RT A from being mixed together.

01First ONThe key crosses its fixed actuation point.
02Continue downThe key stays ON while you keep pressing.
03 · RT DLift to OFFThe key moves upward by the RT D distance.
04ReverseYour finger stops lifting and presses down again.
05 · RT ANext ONThe key moves down by the RT A distance.

Plain rule: actuation starts the first input, RT D clears it, and RT A starts the next input after you reverse.

Page 04 · The GunZ connection

What each setting changes in GunZ.

Rapid Trigger does not perform a technique for you. It changes how much finger travel GunZ needs to receive the OFF and next ON around the movement you already perform.

clears the old input.

  • Lower RT D: less lift before the old direction or action turns OFF.
  • Possible GunZ benefit: a small natural lift can clear sooner between repeated inputs.
  • If it is too low: tiny pressure changes can end a held direction before you meant to release it.
  • If it is too high: the old input may stay active too long and crowd the next part of the sequence.

starts the next input.

  • Lower RT A: less downward re-press before the next ON.
  • Possible GunZ benefit: less finger travel between dashes or repeated directions.
  • If it is too low: a small bounce or unplanned re-press can create an early repeat.
  • If it is too high: the next input may feel late or may not arrive before your finger changes direction again.

Movement and aim still meet in the same fight. If movement becomes quicker than your familiar rhythm, your aim can feel out of sync. That does not prove the mouse setting is wrong; it means the new movement rhythm needs to be judged in real play.

Page 05 · Faster is not always cleaner

The benefit only counts if you can control it.

The smallest number is not the goal. The goal is the least travel you can use without losing intentional movement.

What good tuning can help

  • Less release travel between active inputs.
  • Less re-press travel for the next input.
  • A movement rhythm that feels easier to repeat.
  • More room to match the keyboard to how you actually move.

What poor tuning can cause

  • Directions turning OFF from tiny finger movement.
  • Early or accidental repeated inputs.
  • A faster rhythm that no longer matches your intention.
  • Settings that feel good once but fail across full chains.
Example · not a preset

Why 0.10 mm RT D can be a problem.

  • It asks for only 0.10 mm of upward travel before OFF.
  • That may help a player whose lift is very small.
  • It also leaves very little physical room for pressure changes or finger bounce.
  • If held inputs cut off or movement becomes nervous, raise RT D and test again.

Fact check: 0.10 mm does not mean “0.10 ms.” It is a travel distance.

Page 06 · Protect the comparison

Begin from a GunZ base you can repeat.

Do not tune around one good or bad attempt. Give yourself a known point you can return to.

  1. Duplicate a working profile. Keep the last known setup untouched.
  2. Use one familiar GunZ movement. Choose something you can already perform without thinking about the keys.
  3. Keep the rest fixed. Same keys, map, client, SOCD state, and warm-up.
  4. Run short sets. Look for the same problem more than once.
  5. Write down the pass. Save the last value that stayed intentional.

Starting example used in this project: 1.50 mm actuation · 1.50 mm RT A · 0.55 mm RT D. This is a repeatable base, not a universal recommendation.

Page 07 · Release first

Tune RT D until the old input clears on purpose.

RT D owns the upward part of the Rapid Trigger cycle. Tune it before RT A so you know the first input is actually ending.

  1. Lock actuation and RT A. Do not move three causes at once.
  2. Run the same movement chain. Pay attention to whether the previous direction clears.
  3. If it stays ON too long, lower RT D one step. Less lift will be required for OFF.
  4. If it cuts off early, raise RT D one step. More lift will be required before OFF.
  5. Stop at the first repeatable release. Do not keep lowering it just because the keyboard allows it.

GunZ pass: the old direction or action ends when you intend it to, without staying held and without cutting off from tiny finger movement.

Page 08 · Set the next press

Tune RT A until the next input matches your pace.

Once release is clean, RT A controls how much downward movement is needed after reversal for the next ON.

  1. Keep actuation and the passing RT D fixed. RT A is now the only changing cause.
  2. Repeat the same movement chain. Watch the next dash, direction, or repeated input.
  3. If the next ON is late, lower RT A one step. Less re-press travel will be required.
  4. If it repeats too early, raise RT A one step. More deliberate re-press travel will be required.
  5. Keep the slowest-looking value that feels fully fluent. The goal is control, not the smallest number.

GunZ pass: the next input arrives with your intended dash rhythm and does not appear from a small bounce or unfinished release.

Page 09 · Training, then pressure

Make the setting survive real GunZ.

Training shows whether the input can work. PvP shows whether it still works while your pace and attention change.

Pass 1 · Controlled movement

  1. Warm up on the saved base.
  2. Use one familiar move on level ground.
  3. Run chains of at least five.
  4. Keep the same test conditions for a full session.
  5. Change one value only when one symptom repeats.

Pass 2 · Real players

  1. Take the training pass into normal PvP.
  2. Test against more than one player and pace.
  3. Do not retune after one miss.
  4. If the same input problem repeats, return to the control that owns it.
  5. Save the last setting that stays clean under pressure.

If you doubt a step: the Research Notebook shows the observations and corrections that led to this order.

Page 11 · Follow the symptom

Change the setting that owns the problem.

A repeated symptom is useful. A single miss is just one miss.

Repeated symptomCheck firstWhy
The first input begins too early or too late.It owns the first ON from the released top.
The old direction stays active too long.More upward release happened before OFF than your motion supplied.
A held direction cuts off from tiny movement.The OFF distance may be too small for your natural pressure changes.
The next dash or direction arrives late.It owns the next ON after reversal.

Page 12 · Definitions

Definitions once. References afterward.

Colored terms open the same definitions beside the guide. This section keeps the permanent quick reference.

Keyboard terms

Actuation point

Definition: the key depth where the first press turns ON from the released top.

GunZ connection: when the first direction or action begins.

Rapid Trigger

Definition: movement-relative keyboard behavior that uses travel direction and distance to report OFF and ON again instead of one fixed reset point.

GunZ connection: repeated directions or actions can clear and return with less finger travel.

RT D · Rapid Trigger Deactivate

Definition: the upward distance an active key moves before reporting OFF.

GunZ connection: how much lift clears the old direction or action.

RT A · Rapid Trigger Activate

Definition: the downward distance after reversal before the key reports its next ON while Rapid Trigger remains active.

GunZ connection: how much re-press travel starts the next direction, dash, or repeated action.

Reversal

Definition: the point where key motion changes direction.

GunZ connection: the handoff between lifting the old input and pressing toward the next one.

Split sensitivity

Definition: Wooting's option for assigning separate downstroke/Activate and upstroke/Deactivate distances.

GunZ connection: RT A and RT D can be tested separately instead of sharing one number.

Continuous Rapid Trigger

Definition: a mode that keeps Rapid Trigger active until the key is fully released. Standard Rapid Trigger ends when the key rises above its configured actuation point.

GunZ connection: changing the mode changes where movement-relative behavior remains available during release, so keep it fixed while comparing values.

Other keyboard software

Definition: another Hall-effect keyboard may use different names for the same upstroke and downstroke controls.

GunZ connection: match the function—not only the label—before following the RT D or RT A steps.

SOCD / Snappy Tappy

Definition: a separate feature that decides how opposing directions are resolved.

GunZ connection: it can change directional output without changing Rapid Trigger, so record it and keep it fixed during an RT test.

Total travel and bottom-out

Definition: total travel is the full physical distance from the released top to the deepest position; bottom-out is that deepest position.

GunZ connection: it sets the physical space available for the first ON, release, reversal, and next ON.

Guide terms

GunZ base

Definition used here: a saved, repeatable starting profile that you do not change during comparison.

Checkpoint

Definition used here: a saved value that passed its current test stage and can be restored if the next change performs worse.

Dead dash

Definition used here: a dash you expected did not complete.

GunZ connection: if it repeats, check whether the old input turned OFF and whether the next ON fit the motion you actually made.

RT A-ready boundary

Definition used in the tester: a travel-capacity reference showing the deepest reversal position where the full selected RT A distance can still fit before bottom-out.

Limit: it is not a Wootility control, an OFF point, or a server-timing measurement.

Training calibration

Definition used here: a controlled test of a familiar move before an opponent and pressure are added.

PvP validation

Definition used here: testing a training pass against real players, changing pace, and pressure before saving it as preferred.

Page 13 · What is known

Evidence, limits, and help.

Documented keyboard behavior and personal GunZ testing are useful in different ways.

What the sources support

  • Rapid Trigger follows key motion instead of one fixed reset point.
  • Split sensitivity can use separate upward/deactivate and downward/activate distances.
  • Smaller selected distances require less physical travel.

What this guide does not claim

  • That one profile is correct for every player, keyboard, or server.
  • That a distance in millimeters equals a fixed number of milliseconds.
  • That Rapid Trigger replaces movement practice or fixes every missed input.
